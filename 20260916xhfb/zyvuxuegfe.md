#  TIANJIN FIRST CENTRAL HOSPITAL  #

**水西院区正式启用**

4月12日，天津市第一中心医院新址（水西院区）正式启用。津云就市民想知道的关于水西院区的一些焦点问题采访了我院张雅敏副院长。

**01**

**双院区同质化管理 错位布局**

水西院区坐落于天津市西青区侯台风景区东南侧，东侧临春明路，西侧临文正路，南侧临保山西道，北侧临保泽西道。总建筑面积41万平方米，是全国单体体量最大的公立医院。设计床位2000张，日门诊量7000人次，日急诊量1200人次，可极大程度上缓解老百姓看病难的问题。

“医院实施分批次的搬迁工作，截至目前已有24个临床科室完成搬迁，水西院区在院患者已突破1000人，手术量也逐日增加。”张雅敏副院长说，目前，水西院区日门急诊总量达1300余人次，共开设55类门诊号，涵盖内科、外科、儿科、放射科、放疗科、超声科、肿瘤科、麻醉科、营养科、妇科、生殖健康科、皮肤科等门诊。同时，内外科急诊也已同期展开。水西院区各功能检查室均已齐备，已可开展包括DR\CT\MRI及各类超声、心电图、肺功能、脑电图、肌电图、经颅多普勒、消化内镜、呼吸内镜等各类检查。

对于很多市民关注的水西院区启用后，复康路院区是否保留的问题，张雅敏副院长也做了明确回复：“水西院区全面启用后，复康院区仍然会保留，实现增量与服务功能定位上的错位布局。其中，水西院区以疑难危重患者救治为主，复康院区以老幼妇儿及慢性病治疗为主。双院区将秉持同质化管理，一体化互补发展的原则面向社会提供更好的医疗服务，为京津冀协同发展和健康天津建设做出更大贡献。”

**02**

**“高配”医疗资源为患者提供精准诊疗**

新启用的水西院区在血透中心、放疗中心、手术中心、急诊科等多个领域优化医疗资源配置，同时，空中救援能力进一步提升。

“位于门诊3楼北区的血透中心占地面积约6000平方米，设有3个独立的诊疗区域，168台血液透析机，6台床旁CRRT机，可承载门诊及住院透析患者600余人，血液净化中心管理患者人数及治疗量位居天津市首位并居全国领先行列。”张雅敏副院长介绍。2000平方米的放疗中心可承载日门诊及住院肿瘤放疗患者300余人。科室拥有最先进的设备，不仅能实现无创精确放疗，还能在手术的同时对肿瘤床进行照射，做到放疗定位清晰准确、放射剂量精确计算。

水西院区手术室总面积约14000平方米，共计45个手术间。医院根据日益增加的手术需求又设置了DSA手术间、术中放疗手术间、达芬奇机器人手术间，并配备骨科天玑机器人、神外ROSA机器人、耳鼻喉术中导航系统等医疗设备，为手术患者提供更加优化的手术治疗方案。

3000平方米的水西院区急诊科日接诊量可达1200人次，极端接诊量可达3000人次。“水西院区急诊科将针对急诊疑难、危重疾病开展快速诊疗通道服务，包括床旁血液净化、急诊内镜检查与治疗、DSA检查及治疗、CTA、MRI检查等，实现了以急诊医学科为主导的多病种多学科协作医疗（MDT）。”张雅敏副院长说，水西院区急诊科优化了急诊资源体系，设有创伤中心抢救室、创伤中心手术室、创伤烧伤处置室、EICU、应急指挥中心等功能区。

空中救援作为一中心医院的一大特色，可满足国内主要机型民用救援直升机的起降。停机坪具备无人值守功能，满足24小时全天候救援要求，可直通病房和急诊科。此外，大型康复中心、核医学楼、健康管理中心、感染楼等优质医疗资源也正在筹备中，将陆续投入使用。

**03**

**智能赋能，患者就医更便利**

正在建设中的地铁11号线未来可直通医院地下一层，将实现“医患分开”“缓急分开”，让患者就医更加便利。此外，水西院区设有患者专用地下停车区域和电梯，行车坡道可直通二楼门诊。此外，人性化设计的无障碍设施、3万平方米绿化面积的“康养花园”都将进一步提升患者的就医体验。

住院大楼呈工字型布局，有独立的体检楼、感染楼、核医学楼和实训楼，有地下医学模拟实训中心，有先进的轨道物流和气动物流、独立的医疗废物和被服自动转运系统、全面的安全监控系统……处处体现了智慧医院的设计理念。

水西院区门诊主入口外设置有风雨连廊，可为就诊患者和家属遮风挡雨。入口处的无台阶设计、双向感应门，将方便行动不便的人群进出。门诊中庭周围设置的扶手、公共走廊设置的轮椅、平车……这都将为行动不便者带来便捷。此外，医院还特别针对老年群体提供老花镜，安排工作人员提供协助就诊指引等助老服务。
门诊一楼大厅的一站式“门诊/住院服务中心”、智能化药房、现代化智能摆药机，都使患者就医更加便捷、省时，提升了患者的满意度。水西院区调整了诊区布局，将相关疾病科系安排在同一诊区，如此，可以让患者方便就诊。此外，各诊区内均设有自助服务设施、治疗室、采血室、药房等，同时借助轨道物流与气动物流传输，可有效减少患者在院内往返。
**04**

**自驾、公交车、地铁等均可到达水西院区**

市民前往医院，如自驾前往门诊可定位导航至医院西门，去急诊则导航至医院东门。目前共4条公交线路通往水西院区，分别是633路、640路、869路和347路，可实现与中心城区、地铁、周边区域的接驳。

市民还可以在院内通过众寻导航小程序，输入所停车位信息即可找到车辆。
