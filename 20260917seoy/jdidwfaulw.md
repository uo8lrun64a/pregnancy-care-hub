# 【朝医新闻】石景山院区妇科门诊手术随到随做，检查合格当天做！

> 更新时间：2026-09-17 (UTC+8)

尊敬的患者朋友：
为进一步提升服务质量，优化患者就医体验，北京朝阳医院石景山院区妇科门诊手术时间自3月11日起进行如下调整：
**一、门诊手术时间调整**
原时间：每周一、周三上午

新时间：每周一、周三至周五下午（周二下午暂不安排手术）

符合手术指征且术前化验完善的患者，可享受“随来随做”服务（无需多次往返，当日检查合格后即可安排手术）。

**二、开展手术类别**
包括但不限于以下项目：

人工流产（人流）、清宫术；

普通诊刮术；

宫内节育器放置（上环）及取出（取环）；

外阴赘生物切除术；

前庭大腺脓肿切开引流术；。
**三、就诊温馨提示**
1. 尽量上午就诊：建议患者空腹于上午到院，完成术前检查（如血常规、凝血功能、感染筛查、超声等）。如患者近期在其他医院或体检中心已有相关检查化验结果，请携带前来，部分检查可互认（互认范围按北京市及计划生育手术的相关要求执行）。

2. 手术时间安排：若检查结果符合手术要求，最快可安排当天下午进行手术，减少等待时间。若检查结果不符合手术要求，医生将根据患者的要求和病情安排后续治疗和手术时间。

3. 术前准备：请携带身份证、医保卡及既往病历资料，并穿着宽松衣物。

4. 关于无痛手术：目前门诊暂不提供无痛人流等手术，但可根据患者需求使用局部麻醉。

** 
四、其他说明**
1. 生育保险报销说明：

人流、上环、取环手术等属于生育保险范畴，需挂“计划生育号”（普通医保不报销）。

如已确诊并预约手术，可直接挂“计划生育号”（普通医保不报销）。

如尚未确诊或需评估病情，可先挂“妇科号”，明确需手术后，再挂“计划生育号”。

2. 空腹要求：部分检查需空腹进行，请就诊前禁食禁水6-8小时。

3. 预约途径：可通过医院官网、微信小程序、朝阳健康云提前预约挂号，或直接在医院挂号。

4. 灵活预约：如需周末就诊，或因病情或患者原因无法当天手术，可联系医护人员按患者需求预约手术时间。

5. 术后关怀：手术后根据病情需留观60-120分钟，医护人员将详细指导术后注意事项及复诊时间。因手术后患者可能有不适症状，建议最好有家属或亲友陪同手术。
